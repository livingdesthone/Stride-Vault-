# Stride Vault

A mobile-friendly sneaker shop website with WhatsApp ordering.

## Files
- `index.html` — complete website
- `sneaker-1.jpg` through `sneaker-5.jpg` — uploaded product photos

## Publish with GitHub Pages from your phone
1. Open GitHub and create a new repository called `stride-vault`.
2. Upload all six files from this folder.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Wait a little while. GitHub will show your live site address.

The WhatsApp buttons use Ghana's +233 format for 0206194977.
